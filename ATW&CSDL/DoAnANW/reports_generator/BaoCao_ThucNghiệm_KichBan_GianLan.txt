1. TỔNG QUAN THỰC NGHIỆM VÀ KẾT QUẢ GIẢ LẬP 6 KỊCH BẢN TẤN CÔNG
--------------------------------------------------------------------------------
Hệ thống đã chạy thực nghiệm 6 kịch bản giao dịch mẫu từ Simulation Engine:

- Kịch bản: Account Takeover (ATO) Attack (Chiếm đoạt tài khoản)
  + Mô tả: New Device + New IP + Location Change + 45,000,000 VND high value order.
  + Điểm Rủi Ro (Risk Score): 100 / 100
  + Mức Rủi Ro (Risk Level): CRITICAL
  + Quyết Định Tự Động (Decision): BLOCK
  + Các Quy Tắc Bị Kích Hoạt (6): High Transaction Amount, Unusual Amount Spike, New Device Detected, New IP Address Detected, Location Change / Impossible Travel, Suspicious Composite Fraud Patterns
  + Mẫu Gian Lận Phức Hợp: Account Takeover (ATO), Impossible Travel Teleportation, High-Value Device Anomaly

- Kịch bản: Combined Multi-Vector Attack (Thử thẻ tự động)
  + Mô tả: New Account + New Device + New IP + High Amount + Velocity + Location Change.
  + Điểm Rủi Ro (Risk Score): 100 / 100
  + Mức Rủi Ro (Risk Level): CRITICAL
  + Quyết Định Tự Động (Decision): BLOCK
  + Các Quy Tắc Bị Kích Hoạt (10): High Transaction Amount, Unusual Amount Spike, Transaction Velocity Spike, Failed Payment Velocity, New Device Detected, New IP Address Detected, Location Change / Impossible Travel, New Account Risk, High Failed Payment Rate, Suspicious Composite Fraud Patterns
  + Mẫu Gian Lận Phức Hợp: Account Takeover (ATO), Impossible Travel Teleportation, High-Value Device Anomaly

- Kịch bản: Velocity Burst Attack (Bùng nổ tần suất)
  + Mô tả: 8 consecutive transactions initiated within a 5-minute window.
  + Điểm Rủi Ro (Risk Score): 70 / 100
  + Mức Rủi Ro (Risk Level): HIGH
  + Quyết Định Tự Động (Decision): REVIEW
  + Các Quy Tắc Bị Kích Hoạt (2): Transaction Velocity Spike, Suspicious Composite Fraud Patterns
  + Mẫu Gian Lận Phức Hợp: Transaction Velocity Burst

- Kịch bản: Impossible Travel Anomaly (Di chuyển bất khả thi)
  + Mô tả: Transaction in Ho Chi Minh City, followed by Tokyo 5 minutes later.
  + Điểm Rủi Ro (Risk Score): 100 / 100
  + Mức Rủi Ro (Risk Level): CRITICAL
  + Quyết Định Tự Động (Decision): BLOCK
  + Các Quy Tắc Bị Kích Hoạt (5): Unusual Amount Spike, New Device Detected, New IP Address Detected, Location Change / Impossible Travel, Suspicious Composite Fraud Patterns
  + Mẫu Gian Lận Phức Hợp: Account Takeover (ATO), Impossible Travel Teleportation

- Kịch bản: Unusual High Amount Scenario (Bất thường giá trị lớn)
  + Mô tả: 30,000,000 VND order (50x user average) from familiar device.
  + Điểm Rủi Ro (Risk Score): 45 / 100
  + Mức Rủi Ro (Risk Level): MEDIUM
  + Quyết Định Tự Động (Decision): APPROVE
  + Các Quy Tắc Bị Kích Hoạt (2): High Transaction Amount, Unusual Amount Spike
  + Mẫu Gian Lận Phức Hợp: Không có

- Kịch bản: Normal Transaction Scenario (Giao dịch hợp lệ bình thường)
  + Mô tả: Routine 500,000 VND purchase from registered home device and IP in HCM city.
  + Điểm Rủi Ro (Risk Score): 0 / 100
  + Mức Rủi Ro (Risk Level): LOW
  + Quyết Định Tự Động (Decision): APPROVE
  + Các Quy Tắc Bị Kích Hoạt (0): Không có
  + Mẫu Gian Lận Phức Hợp: Không có

2. CÁC HÌNH THỨC GIAN LẬN ĐÃ PHÁT HIỆN VÀ CÁCH THỨC PHÁT HIỆN (WITH CODE MAPPING)
--------------------------------------------------------------------------------

[HÌNH THỨC GIAN LẬN 1]: CHIẾM ĐOẠT TÀI KHOẢN (ACCOUNT TAKEOVER - ATO)
- Cách phát hiện: Kết hợp đồng thời 4 yếu tố rủi ro: Thiết bị mới (is_new_device) + IP mới (is_new_ip) + Thay đổi vị trí (location_changed) + Giá trị đơn hàng bất thường (amount_ratio >= 3 hoặc amount > 15M VND).
- Dòng code thực thi:
  + python_app/fraud/rules/suspicious_pattern_rule.py: Dòng 10 - Dòng 26 (Hàm evaluate_composite_patterns)
  + python_app/fraud/device_analyzer.py: Dòng 6 - Dòng 24 (Phát hiện thiết bị lạ)
  + python_app/fraud/location_analyzer.py: Dòng 12 - Dòng 61 (Phát hiện IP và khoảng cách địa lý)

[HÌNH THỨC GIAN LẬN 2]: MÁY THỬ THẺ TỰ ĐỘNG (CARD TESTING ATTACK)
- Cách phát hiện: Phát hiện đơn hàng giá trị nhỏ (< 2,000,000 VNĐ) kết hợp với số lần thanh toán thất bại dồn dập (failed_transactions_last_5m >= 2) và xoay vòng nhiều thẻ/phương thức thanh toán khác nhau (different_payment_methods_15m >= 2).
- Dòng code thực thi:
  + python_app/fraud/rules/suspicious_pattern_rule.py: Dòng 28 - Dòng 44
  + python_app/fraud/rules/failed_attempt_rule.py: Dòng 10 - Dòng 33 (Kiểm tra failed velocity)
  + python_app/fraud/rules/payment_method_switch_rule.py: Dòng 8 - Dòng 28 (Đếm số phương thức thanh toán)

[HÌNH THỨC GIAN LẬN 3]: DI CHUYỂN BẤT KHẢ THI (IMPOSSIBLE TRAVEL TELEPORTATION)
- Cách phát hiện: Tính khoảng cách địa lý theo công thức Haversine giữa 2 tọa độ GPS (Lat/Lon) của 2 giao dịch liên tiếp. Tính vận tốc di chuyển speed_kmh = (distance_km / (time_diff_seconds / 3600)). Nếu vận tốc vượt quá ngưỡng vật lý 800 km/h, hệ thống kết luận di chuyển bất khả thi.
- Dòng code thực thi:
  + python_app/fraud/location_analyzer.py: Dòng 12 - Dòng 48 (Hàm calculate_haversine_distance & analyze_location_risk)
  + python_app/fraud/rules/location_change_rule.py: Dòng 10 - Dòng 37 (LocationChangeRule)
  + python_app/fraud/rules/suspicious_pattern_rule.py: Dòng 63 - Dòng 75

[HÌNH THỨC GIAN LẬN 4]: BÙNG NỔ TẦN SUẤT GIAO DỊCH (TRANSACTION VELOCITY BURST)
- Cách phát hiện: Theo dõi cửa sổ thời gian trượt (Sliding Windows: 1m, 5m, 15m, 1h). Nếu số lượng giao dịch trong 5 phút transactions_last_5m >= 5 hoặc vượt ngưỡng cài đặt (3, 5, 8 txs), kích hoạt cảnh báo rủi ro tần suất cao.
- Dòng code thực thi:
  + python_app/fraud/velocity_analyzer.py: Dòng 10 - Dòng 47 (Hàm calculate_velocity)
  + python_app/fraud/rules/velocity_rule.py: Dòng 10 - Dòng 38 (VelocityRule)

[HÌNH THỨC GIAN LẬN 5]: BẤT THƯỜNG GIÁ TRỊ GIAO DỊCH (HIGH-VALUE & UNUSUAL AMOUNT ANOMALY)
- Cách phát hiện: So sánh số tiền đơn hàng hiện tại với trung bình tiêu dùng 30 ngày của người dùng (amount_ratio = current_amount / avg_amount_30d). Kích hoạt quy tắc nếu số tiền > 20M/50M/100M VNĐ hoặc tỷ lệ gấp 5x/10x/20x giá trị lịch sử.
- Dòng code thực thi:
  + python_app/fraud/amount_analyzer.py: Dòng 8 - Dòng 26 (Hàm analyze_amount_risk)
  + python_app/fraud/rules/high_amount_rule.py: Dòng 10 - Dòng 38 (HighAmountRule)
  + python_app/fraud/rules/unusual_amount_rule.py: Dòng 10 - Dòng 38 (UnusualAmountRule)
