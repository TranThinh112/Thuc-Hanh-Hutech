# Thư Mục: reports_generator

Thư mục chứa các kịch bản và dữ liệu phục vụ tự động hóa tạo báo cáo, tài liệu Word và trích xuất kịch bản thực nghiệm:
- `chapter3_sec1.json` -> `sec5.json`: Dữ liệu JSON các chương báo cáo.
- `generate_final_report.py`, `build_complete_report.py`, `make_docx.py`: Script xuất báo cáo đồ án docx/txt.
- `BaoCao_ThucNghiệm_KichBan_GianLan.txt`, `doc_dump.txt`: Kết quả chạy thực nghiệm và dump tài liệu.
