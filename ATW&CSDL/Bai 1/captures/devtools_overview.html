1. Khởi tạo truy cập (Initial Page Load):

• Trình duyệt gửi request GET /login nhận về mã 200 OK với trang HTML chính (2.5 kB).

• Sau khi bóc tách DOM, trình duyệt lần lượt tải tiếp các tài nguyên phụ trợ gồm 3 CSS files (app.css, sauce.css, font-awesome.css), 3 JavaScript libraries (jquery, foundation) và 2 fonts chữ (woff2).


2. Thực hiện Đăng nhập (User Authentication):

• Người dùng điền Username & Password, bấm nút Login.

• Trình duyệt kích hoạt request POST /authenticate gửi kèm payload trong Body (Content-Type: application/x-www-form-urlencoded).

• Server xác thực thông tin và phản hồi mã 303 See Other kèm Header Location: /secure điều hướng trình duyệt.


3. Tải trang bảo mật (Secure Area):

• Trình duyệt tự động gửi tiếp request GET /secure và hiển thị thông báo "You logged into a secure area!".
